# тембр

Обработка звука для микрофона Fifine AM8 на Windows: гейт, шумодав (RNNoise), эквалайзер, компрессор, лимитер, пресеты и мастер калибровки. Звук уходит в виртуальный кабель VB-Cable, программы слушают `CABLE Output`.

Статус: альфа. Ядро проверено тестами на синтетическом сигнале, приложение проверено на компиляцию под Windows. На живом микрофоне и на самой Windows ничего ещё не запускалось.

## Сборка установщика
Репозиторий собирается на GitHub Actions (`.github/workflows/build.yml`, runner `windows-latest`):
1. Создайте пустой приватный репозиторий на GitHub.
2. В папке проекта: `git init -b main`, `git add .`, `git commit -m "init"`, `git remote add origin <адрес репозитория>`, `git push -u origin main`.
3. Вкладка Actions, сборка `windows-installer` (или Run workflow). Через 10-15 минут в Artifacts появится `timbre-windows-installer` с `.exe`.

Локально на Windows: нужны Rust, Node 22 и Visual Studio Build Tools. Затем `npm ci` и `npm run build`.

## Устройство
- `crates/timbre-dsp`: цепочка обработки без привязки к интерфейсу. `cargo test -p timbre-dsp` (11 тестов: фильтры, гейт, компрессор, лимитер, громкость, задержка).
- `src-tauri`: захват (cpal, WASAPI), вывод в `CABLE Input`, трей, глобальная горячая клавиша, автозапуск. События уровней уходят в окно 50 раз в секунду.
- `src`: интерфейс. Вне Tauri работает на демо-сигнале (`js/sim.js`), внутри Tauri `js/native.js` подменяет его реальным движком.
- `preview/`: одиночные файлы интерфейса для просмотра в браузере (`node build-preview.mjs`).

## Что не проверено и требует настройки на живых данных
- Звук с AM8 и вывод в CABLE: может не открыться при нестандартных форматах устройства. Причина будет в настройках, строка `engine-msg`.
- Шумодав: RNNoise в обоих режимах. DeepFilterNet запланирован, но не подключён. Подавление проверить на реальной речи.
- Целевые уровни спектра для автонастройки эквалайзера (`TARGET` и `CAUTION` в `js/native.js`) прикидочные.
- Громкость показывается как короткий LUFS без привязки к калибровке тракта.
- Нет подписи установщика: Windows SmartScreen покажет предупреждение, «Подробнее», «Выполнить в любом случае».
- Трей использует собственное меню Windows, а не `tray.html`.
